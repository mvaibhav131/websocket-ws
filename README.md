# WebSocket Integration – Connection Demonstration

This repository demonstrates how to establish a **WebSocket connection between a Node.js server and a client** using the `ws` library.

The example shows how a client connects to the WebSocket server, sends messages, receives messages, and handles connection events.

## How WebSocket Connection Works

A WebSocket connection starts as a normal **HTTP request**. If the server supports WebSocket connections, the HTTP connection is upgraded to a persistent WebSocket connection.

The successful upgrade response uses:

```http
HTTP/1.1 101 Switching Protocols
Upgrade: websocket
Connection: Upgrade
Sec-WebSocket-Accept: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

### HTTP/1.1 101 Switching Protocols

`101 Switching Protocols` means that the server has accepted the client's request to switch from the HTTP protocol to the WebSocket protocol.

After this upgrade, the connection remains open and both the **client and server can communicate in real time**.

### Upgrade: websocket

```http
Upgrade: websocket
```

This tells the server that the client wants to upgrade the existing HTTP connection to a WebSocket connection.

### Connection: Upgrade

```http
Connection: Upgrade
```

This indicates that the current HTTP connection is being upgraded to another protocol.

### Sec-WebSocket-Accept

```http
Sec-WebSocket-Accept: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

`Sec-WebSocket-Accept` is a value generated by the WebSocket server during the handshake.

It is calculated from the client's `Sec-WebSocket-Key` and is used by the client to verify that the server accepted the WebSocket handshake.

## Connection Flow

```text
Client
  |
  | HTTP WebSocket Handshake
  |---------------------------->
  |
  | HTTP/1.1 101 Switching Protocols
  |<----------------------------
  |
  | WebSocket Connection Established
  |
  |<============================>
  |        WebSocket
  |        Connection
  |<============================>
  |
  | Send / Receive Messages
  |
```

## Example

The WebSocket server runs on:

```text
ws://localhost:9000
```

Once the connection is established:

1. The client connects to the WebSocket server.
2. The server accepts the connection.
3. The server sends a connection message to the client.
4. The client can send messages to the server.
5. The server receives and responds to those messages.
6. Either side can close the connection.

## WebSocket Lifecycle

```text
Connection
    ↓
Message
    ↓
Message
    ↓
Message
    ↓
Close
```

The main WebSocket events used in this demonstration are:

* `open` – Connection successfully established.
* `connection` – A client connects to the server.
* `message` – A message is received.
* `error` – A WebSocket error occurs.
* `close` – The WebSocket connection is closed.
